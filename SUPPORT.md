# Support

Use GitHub Issues for reproducible toolkit defects, documentation problems, privacy-model gaps, evidence-acquisition questions, and bounded change proposals. Include the affected version/revision, expected and observed behaviour, and relevant fixtures/evidence.

Security or undisclosed privacy vulnerabilities must follow [`SECURITY.md`](SECURITY.md) and must not be disclosed publicly before remediation.

DPIP owns the composition privacy contract and evidence needed to support scoped end-to-end privacy claims. It does not redefine the semantics of DTG Credentials, Trust Tasks, ZKP constructions, agent naming, transports, wallets, discovery policy, or external governance systems.
