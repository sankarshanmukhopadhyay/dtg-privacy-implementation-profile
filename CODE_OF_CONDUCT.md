# Code of Conduct

Participation in this project requires professional, respectful, and good-faith collaboration.

Technical, privacy, assurance, and governance disagreement is expected. Critique should address claims, evidence, implementation, authority, and consequences rather than individuals. Harassment, discrimination, threats, and deliberate intimidation are not acceptable.

Maintainers may remove content or restrict participation when behaviour materially undermines a safe and productive project environment. Serious concerns should be raised privately with the repository maintainer.
